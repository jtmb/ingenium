## WSL is not an equivalent original-URI lease

[flock](https://man7.org/linux/man-pages/man2/flock.2.html) is advisory. Holding an fd and taking flock does not stop an uncooperative writer or a rename/replacement of path ancestors. Descriptor-relative capture can safely capture bytes, but a later engine pathname reopen can resolve a different object.

[F_SETLEASE](https://man7.org/linux/man-pages/man2/F_SETLEASE.2const.html) is also insufficient for this constructor: it applies only to regular files, not an immutable retained ancestor chain, and the kernel forcibly breaks it after lease-break-time if the holder does not downgrade. An operation timer or SIGIO acknowledgment is not proof that the engine completed its read. No global sysctl, mount, namespace, process policy or privileged broker is changed here.

WSL retains the real capture-to-effective-bytes path plus explicit source/MIME/projection compatibility gates. A true equivalent needs an actual immutable source/namespace or same-engine materialization owner with original FD/process/transport and directory-namespace semantics. It cannot be replaced with a false lease or a post-read path check. Windows directory and UNC roots remain separate pending constructors too.
