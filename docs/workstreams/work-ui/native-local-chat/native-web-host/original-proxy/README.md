This is a source proposal, not a functioning/qualified Web proxy. It adds six files through `original-proxy.patch`: two new modules and four original module/facade insertions. `assembly-manifest.json` pins exact pre/postimages; `preimages.json` records the actual integrated Native staged blobs inspected, including the Root-corrected child/auth sources. No shared Native files, runtime, compiler, service, browser, model, GPU, listener, dependencies or downloads were touched by this worker.

The concrete producer is grounded: `routes/local_workspaces/web_original.rs::acquire` reads the original ProjectStore, requires the saved local session, and acquires the actual LocalWorkspaceBinding. Its callback rechecks BOTH binding.verify_current and require_local_session under that original store's nonblocking lock. LiveAgent delegates to the existing LiveRuntime. LiveRuntime holds the existing retained engine lock, verifies the actual process/registration through current_engine_instance_id, observes the authenticated server PID/version, checks exact session/project/directory, and captures the credential revision. The opaque lease is neither deserializable nor constructible from positive availability/URL/port metadata. A subsequent mismatch permanently revokes that original lease. A random native binding ID/nonce does not substitute for any observed identity.

The request producer receives bytes ONLY at the private native proxy boundary, after its native child/origin authentication. It accepts no engine URL/token or renderer generic-invoke request. It records one fresh native operation UUID; exact normalized method/route; ordered decoded scope/query pairs; a closed content-header set; complete unmodified request-body bytes; exact original owner/session/project/instance/PID/version/revision; and opaque lease identities. A domain-separated, length-framed SHA256 binds the full input. Native transport authentication, Cookie, Host, Origin, Connection, WebSocket negotiation and other ambient headers cannot enter the replayable content envelope. The genuine transport must validate/strip its own headers separately; this is not a declaration that those transport routes are absent or disabled.

`inspect_local_web_prompt` reads a separate JSON view of the full original and retains raw bytes. It checks actual session/model/agent, upstream metadata.model.modelID/providerID/variant, current visible agents, managed-profile restrictions, archived/custom-assistant policies, image capability and actual skill catalog. Files, skill mention objects, agents, metadata, parts, queue/steer delivery, resume and upstream message ID are not translated into AgentTurn or reserialized. This inspection is NOT full admission or a dispatch token. Full broker/file/attachment policy closure and repeat-under-dispatch-lock integration remain required.
