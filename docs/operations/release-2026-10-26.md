## Security and validation

Production dependency versions and integrity hashes are unchanged. npm12 recalculates one optional macOS fsevents development marker without changing its version or integrity.

Focused reruns resolved the identified failures: current SDK response wrappers, isolated mock history, temporary-root guards, complete compiled dependency/launcher fixtures, current migration and plugin inventories, aggregate-size limits, and realistic disk-operation budgets. Backup maintenance, browser gateway, accessibility, command destination safety and reset fixtures passed in an isolated unprivileged container. The migration controls were exercised in the actual dashboard: save and reload, source snapshot creation and integrity validation, step-up verification, and runbook download. Twenty-six UI route families were independently navigated. This navigation audit does not claim every destructive action or integration branch was exercised.
