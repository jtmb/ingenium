# Hosted Customize composition and domain runtime closure

The Customize catalog uses the existing authenticated project permission boundary and complete unarchived skill records, including disabled skills. The installation namespace is exposed as System only through the actual existing global-project mapping. Public and Personal scopes remain unavailable until a real authority supplies them. Catalog reads do not install, activate, synthesize or alter skills; existing lifecycle routes retain writes.

Plugin editing reads API-owned source first, including an intentionally empty string. Legacy file-only source is bounded to the registered plugin directory and a stable regular file. A refused source read keeps the editor closed and displays an error; no blank editor is substituted for unreadable source.

Work and Customize own immersive layouts. The shared application rail keeps Chat, Tasks, all features, settings and account access reachable. Existing navigation providers and legacy feature routes remain intact.

The API build materializes reviewed `.mjs` domain/shared-package imports into its distribution. An AST transformation changes import/export specifiers only; ordinary string values and original source bytes are unchanged. Unknown dependencies and redirected outputs fail before publication. The emitted closure includes hashes for source and output modules. The fixture helper similarly binds shared domain source imports to the original checkout without copying dependencies or cached builds.

Validation: API/dashboard type checking, 51 hosted catalog/auth policy cases, 11 plugin source/API cases, 22 Customize React cases, 16 legacy Skills cases, 31 catalog/write policy cases, 21 navigation/container cases and four runtime/fixture closure cases passed in coordinator qualification. The earlier API emission resolved all 26 runtime modules. These are source and isolated fixture checks, not native, visual, production migration or release acceptance. Browser qualification and exact integrated deployment remain coordinator gates.
