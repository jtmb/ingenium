# Managed memory recall

The public lifecycle recall route now reads a bounded candidate window, primes the existing OpenCode client against the selected canonical messages, and consumes that proof during synchronous authorization and source checks. It reacquires original manager placement around asynchronous reads, revalidates current source-history membership and execution scope, and refuses container replacement. A Context checkpoint alone does not establish canonical engine source availability.

The original runtime mapping supplies the container target and directory. No caller URL, credential, owner identifier or fabricated engine boot identity grants authority. The observed Docker provisioning revision may precede the mutable Core runtime revision: provisioning labels do not advance with leases or READY/activity transitions. Qualification still requires the exact container, daemon, owner, workspace, binding hash, security epoch, health and observation lifetime; a future provisioning revision is rejected. The resulting placement retains the current Core revision and the resolver checks that revision again.

The route returns the existing recall data and bounded source-window counts. It does not expose denied source identifiers through the added window metadata. It performs no model work, transcript writes or queue admission. Per-chat opt-out and deletion remain effective before source transport. Selected source edits withhold affected memories; a later unrelated unfinished turn does not invalidate an already selected completed pair.

Coordinator evidence: 13 actual lifecycle HTTP cases passed using the real authentication, authorization, CSRF, Core database and route composition, with explicitly fixture manager/engine transport. The 90 source cases passed with no skips, including a file-backed close/reopen persistence case; API/Core source type checking also passed. These checks do not establish attended UI, production engine persistence, full restore, generation Jobs, combined turn budgets or release acceptance. Entries inspection and those remaining consumers still require their own composition.
